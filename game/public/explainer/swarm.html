The actual point

The thing being studied is the team, not the genius.

It is easy to make one clever agent do one clever thing. RIG is built around the harder, more interesting question: can four agents, each seeing only part of the world, sharing a sparse and structured reward, beat an opponent that is also trying — by coordinating, not by being individually brilliant?

Lower stakes, same algorithm

This is a not-quite-robotics control problem. Continuous control, partial observation, an adversary, reward that only arrives at meaningful moments. Nobody gets hurt if a rigger fumbles — but the algorithmic class is the same one that shows up when real machines have to work as a group. RIG is a place to practice that class where mistakes are just a missed Loop.

Foosball robots, but the table is physics and the players have to agree with each other.

The layered mind of a side

A team is not one policy. It is a stack.

How a rigger decides

Underneath each role, the controllers are built on two ideas worth naming honestly:

Expected Free Energy

Active inference: an agent acts both to fulfil its preferences and to reduce its uncertainty about the world. It doesn't only chase the goal — it also moves to find out what it needs to know to chase it well. That's why a rigger will reposition for a better read, not just lunge.

Bennett-style w-maximization

Among policies that are good enough, prefer the weakest sufficient one — the simplest commitment that still does the job. Weaker policies generalise: they bend to new situations instead of overfitting one. The team stays robust rather than brittle-clever.

Coordination is the design target

The roles are chosen so the four need each other. A primary interceptor commits to the bell. A shadow is already where the rebound will be. An outlet is positioning for the phase that hasn't happened yet. A spacing pressure keeps them from collapsing onto the same point and becoming one redundant agent in four bodies. Take any one away and the shape breaks — which is exactly the property you want when the thing you're studying is coordination itself.

Success isn't a great individual play. It's four decisions that only make sense together.

Honest about where it is

This is an evolving experiment, and that's the good part. The controller stack is not a finished result being shown off — it is a thing in motion, and because every match is deterministic and watchable, you can actually see it get better between versions instead of taking a number's word for it. The weak spots are visible too. That's the deal: nothing here is staged.
