Watching it learn

The web game is the visualizer.

Most learned policies live in a log file. This one lives in the same arena you watch for fun: select a team to be the learned swarm, press play, and the match you see is the policy running — deterministically, replayable frame-for-frame, no separate demo, no cherry-picked clip.

The deterministic core, wrapped as a Gym

Because the simulation is exactly repeatable, it makes a clean training environment. The same engine exposes a familiar loop: reset, step, snapshot, restore — plus an agent-control selector so a learner can drive a subset of riggers while the rest run the existing baseline. You can train one side against a known opponent, branch from any snapshot, and re-run a situation as many times as you like with nothing else moving.

One network, four egocentric views

The trainable swarm policy is a single shared-parameter network. Every rigger runs the same weights and sees only its own view of the world. There is no shared brain, no central controller piped into all four. If coordinated behaviour appears, it appears because it had to emerge from identical agents reading different slices of the same situation — which is the honest version of the question.

No shared brain. If they cooperate, it's because cooperation emerged.

How it's trained

Gradient-free evolution strategies

The shared network is trained by evolution strategies — perturb the weights, run deterministic matches, keep what wins. No backprop through the simulator required; the engine just has to play, repeatably, which it does.

An evolutionary learner on the controller itself

Alongside the neural swarm, an evolutionary learner tunes the structured controller's own parameters — two routes up the same mountain, both judged by the same game.

The reward is the game itself

This is the part that keeps it honest. The reward is the match's own outcome — possession, score, contest — not a hand-tuned ranker quietly teaching the agents to look good. To densify a signal that would otherwise be painfully sparse, RIG uses potential-based shaping that is provably policy-invariant: it makes the gradient less lonely without changing which policy is optimal. Strategic quality is assessed separately, by an offline judge, so the thing being optimised and the thing being graded for craft are not the same knob.

It's optimised for winning the game, not for impressing a metric.

Then you just watch it

The payoff: there is no gap between training and demo. The learned weights load into the same browser game. Pick the learned swarm as a side, run the match, and what you see is exactly what the policy does — and because it's deterministic, you can replay the same match, scrub it, and compare a later version against an earlier one on the identical seed.

You can literally watch it get better.
